# Message shapes

All of these go to the review DM (their DM to themselves). Your own replies in a review thread always start with 🤖 so the next run can tell them apart from the owner's, since both appear under the owner's name.

## Slack draft

```
[#<id>] <category> · reply to <who> in <#channel or DM>
Context: <one line: what they asked, and anything you avoided committing to>
Original: <permalink>

<draft text, exactly what would be posted>

Reply in this thread: approve · edit: <your version> · skip
```

## Email draft

```
[#<id>] email · to <recipients> · <generic subject label, not the subject>
Context: <one line>
Gmail draft: <link to the draft>

It's in your Gmail Drafts. Send it from there when ready, or reply here edit: <text> and I'll update it, or skip.
```

## Note task result

```
[#<id>] from your notes · <short label>
Found in: <link to the notes doc>
What I did: <one line>
Result: <link to the new doc in Agent drafts, or the draft below>

Reply approve if this is right, edit: <what to change>, or skip.
```

## Needs you (one message per check-in, only if there are any)

```
Needs you (<n>)
• <who> in <where>: <kind of thing, e.g. asks you to approve spend> · <link>
```

## Closing replies (in the draft's thread)

- `🤖 Posted: <permalink>`
- `🤖 Gmail draft is ready; send it from Gmail.` / `🤖 Gmail draft updated.`
- `🤖 Skipped.`
- `🤖 Expired. Reply approve to revive.`
- `🤖 Got it: <rule>, saved.` (when they gave a standing instruction)

## Daily brief (under 40 lines)

```
Daily brief · <date>

Waiting on you (<n>)
• #<id> <label> · <age> · <link>

Done today (<n>)
• #<id> <label> · posted | in Gmail | skipped | expired

Couldn't do (<n>)
• <what> · <why>

Tomorrow
• <n> meetings, first at <time>; <any meeting related to a waiting item>
```
